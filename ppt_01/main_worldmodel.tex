\WinterTextImageFrame
  {World Model 的直觉}
  {人类并不是只对当前观测做反应，而是在脑中构建一个可预测的世界。World Model 的目标也是类似的：把高维观测压缩为潜变量，并在潜空间中预测未来状态，从而让智能体在“想象”中规划行为。}

  {类比：先形成世界表征，再基于表征做决策。}

\WinterTwoImageCompareFrame
  {任务场景：从像素到行动}
  {\wmgen{P1-car-racing-frame.png}}

  {\wmasset{P4-world-model.png}}
  {World Model 把“观测、记忆、控制”拆开，让模型先学习环境动力学，再训练控制策略。}

\WinterSection{assets/hybrid/section02_bg.png}{方法框架}

\WinterArchitectureFrame
  {V-M-C 总体架构}
  {\wmgen{P6-V-M-C-arch.png}}
  {Vision Model 负责压缩观测，Memory Model 负责预测潜状态演化，Controller 根据潜变量和记忆状态输出动作。}

\WinterArchitecturePointsFrame
  {Vision Model：学习低维表征}
  {\wmgen{P7-Vision-Model.png}}
  {作用}
  {把原始图像编码成低维潜变量，降低后续模型学习难度。}
  {验收标准}
  {重建图像应保留道路、障碍和视野结构，避免压缩后丢失关键控制信息。}

\WinterDualArchitectureFrame
